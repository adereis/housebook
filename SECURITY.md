# Security Policy

Housebook holds a household's financial records, so security reports
are welcome and taken seriously.

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub's
[private vulnerability reporting](https://github.com/adereis/housebook/security/advisories/new)
rather than in a public issue.

Include what you found, how to reproduce it, and the impact you
expect. You will get an acknowledgement, and the fix will be
coordinated with you before any public disclosure.

## Scope

In scope: the code in this repository, including the web dashboard,
the ingest pipeline, workspace sync, and the LAN deployment examples
in `deploy/lan/`.

Out of scope: your own workspace contents and your cloud storage
account. Real financial data never belongs in this repository; if you
find some, report it the same private way.

## Supported versions

Only the latest commit on `main` is supported.
